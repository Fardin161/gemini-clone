# gemini-clone
Gemini AI clone using JavaScript and Gemini API
This is a simple Gemini AI clone built using **JavaScript** and the **Gemini API**.  
It allows users to interact with a conversational AI in a user-friendly UI.

## 🚀 Features
- Chat interface similar to Google's Gemini
- Gemini API integration
- Responsive design
- Realtime typing effect

## 🛠️ Built With
- HTML, CSS, JavaScript
- Gemini API
